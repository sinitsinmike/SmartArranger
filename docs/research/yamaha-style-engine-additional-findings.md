# Yamaha Style Engine — дополнительные исследовательские находки

**Статус:** дополнительная заметка к `yamaha-style-engine-initial-findings.md`.  
**Назначение:** зафиксировать новые официальные материалы Yamaha и технически важное патентное свидетельство.  
**Важно:** это не полная спецификация Yamaha Style Playback Engine. Модельно-зависимые сведения нельзя автоматически переносить на все инструменты Yamaha.

---

## 1. Новые официальные материалы Yamaha

### 1.1. PSR-SX920/SX720 Reference Manual — MIDI-вход для распознавания аккордов

Официальный документ:
https://data.yamaha.com/files/download/other_assets/5/2328055/PSR-SX920_reference_manual_En_B0.pdf

В разделе MIDI Settings, печатная страница 127, описаны параметры:

- **On Bass Note** — выбор MIDI-каналов, данные с которых используются для определения басовой ноты при воспроизведении Style.
- **Chord Detect** — выбор MIDI-каналов, данные с которых используются для определения типа аккорда при воспроизведении Style.

Там же перечислены MIDI templates, в том числе варианты для MIDI Accordion и MIDI Pedal. Это важное свидетельство: в реальном инструменте определение басовой ноты и определение типа аккорда могут получать данные по отдельно назначенным MIDI-каналам.

**Следствие для Smart Arranger:** нельзя считать, что Yamaha chord recognition всегда сводится к анализу одного набора одновременно удерживаемых нот на одной клавиатурной зоне. Нужно исследовать раздельные источники chord и bass, а также режимы MIDI-ввода.

Ограничение: этот раздел описывает конфигурацию MIDI-входа конкретной модели; он не раскрывает сам алгоритм распознавания.

### 1.2. Официальная страница загрузок PSR-SX920

https://usa.yamaha.com/products/musical_instruments/keyboards/arranger_workstations/psr-sx920/downloads.html

На странице перечислены не только Owner's Manual и Reference Manual, но и:

- Data List;
- Additional Data List;
- текстовые версии руководств;
- MIDI Song to Style Owner's Manual;
- MIDI Song to Style v1.2.0 Supplementary Manual;
- Voice List for MIDI Song to Style;
- материалы по Audio Phraser.

Особенно полезны текстовые версии Reference Manual и Owner's Manual: их проще полнотекстово искать и сопоставлять с PDF. Data List и Additional Data List нужно изучить отдельно — они могут содержать сведения, отсутствующие в пользовательском описании функций.

### 1.3. MIDI Song to Style v1.2.0 Supplementary Manual

Официальная страница загрузок:
https://usa.yamaha.com/products/musical_instruments/keyboards/arranger_workstations/psr-sx920/downloads.html

В списке документов Yamaha присутствует supplementary manual версии 1.2.0. По опубликованному описанию документа, программа различает режимы **2Main** и **4Main**, а также форматы **SFF** и **SFF GE**. В режиме 2Main есть ограничения по составу Fill In: в частности, Fill In может содержать только Rhythm 1/2, а остальные партии Main продолжают воспроизводиться.

Это важно для интерпретации файлов: нельзя предполагать, что каждый Fill обязательно является полностью самостоятельным набором всех партий. Состав реально воспроизводимых партий зависит от режима/формата и правил совместимости.

**Оговорка:** детали supplementary manual необходимо сверить непосредственно с официальным PDF перед реализацией. Нельзя основывать парсер только на кратком описании на стороннем сайте.

## 2. Патент Yamaha: смена аккорда внутри секции не обязательно применяется немедленно

### JP2004294595A — Device and program for automatic accompaniment

Публикация:
https://patents.google.com/patent/JP2004294595A/en

Правообладатель/первоначальный заявитель: Yamaha Corporation.  
Приоритет: 26 марта 2003 года.  
Публикация: 21 октября 2004 года.  
Патентная публикация описывает способ автоматического аккомпанемента с учётом chord progression внутри секции.

Суть раскрытого решения (пересказ аннотации и описания патента):

- для паттерна секции может учитываться исходная/эффективная информация об аккорде в начале воспроизведения секции;
- последующие сведения о смене аккорда, поступающие посреди воспроизведения этой секции, в описанном режиме могут не передаваться в генератор аккомпанемента;
- цель — сохранить естественное звучание паттерна, когда он был выбран с учётом последовательности аккордов.

**Почему это важно:** это прямое техническое свидетельство Yamaha, что обработка chord changes внутри секции может быть сложнее, чем «каждый новый аккорд немедленно транспонирует все звучащие партии».

**Критическое ограничение:** патент описывает раскрытый способ/вариант устройства, но не доказывает, что PSR-SX920, Genos или любая конкретная современная модель использует именно этот алгоритм. Нельзя превращать патентное описание в универсальное правило Yamaha Style.

Для Smart Arranger это означает: необходимо различать как минимум:
1. смену аккорда, которую движок распознал на входе;
2. момент, когда гармоническое состояние разрешено применить к конкретной секции/партии;
3. правила конкретного NTR/NTT/RTR и самого Style.

Не следует пока выбирать для Smart Arranger режим «Immediate», «Next Beat» или «Next Bar» для chord changes без дополнительного источника.

## 3. Уточнение по предыдущему исследованию

Уже найденные документы SX920/SX720 дают подтверждения по нескольким независимым слоям:

- **Section Change Timing** — правила переходов между секциями и настройки поведения Intro/Ending для этой модели/поколения.
- **Chord Fingering** — доступные пользователю режимы распознавания аппликатуры.
- **MIDI Settings** — выбор каналов для Chord Detect и On Bass Note.
- **SFF/CASM** — правила адаптации нот Style к гармонии, включая Source Root/Chord, NTR, NTT, High Key, Note Limit и RTR.

Эти слои нельзя смешивать. Например, описание NTR/NTT не определяет, когда движок принимает новый аккорд, а настройка Chord Detect не раскрывает внутренний алгоритм распознавания.

## 4. Что ещё нужно исследовать

1. Скачать и постранично разобрать официальный SX920/SX720 Reference Manual, особенно разделы Chord Fingering, Style playback, Section Change Timing, Style Retrigger и MIDI Settings.
2. Извлечь из официальных Data List и Additional Data List сведения, полезные для Style/Voice/Part mapping.
3. Проверить supplementary manual MIDI Song to Style v1.2.0 по оригинальному PDF, особенно 2Main/4Main, SFF/SFF GE и назначение партий Fill In.
4. Сопоставить эти сведения с SX900/SX700 и Genos/Genos2, фиксируя различия по моделям и прошивкам.
5. Найти другие патенты Yamaha по chord recognition, chord progression, NTR/NTT, section scheduling и note handling. Для каждого патента отдельно указывать, что именно он доказывает, и чего не доказывает.
6. Для нераскрытых деталей подготовить воспроизводимые испытания на конкретной модели Yamaha с записью MIDI OUT/USB MIDI и временных меток.

## 5. Правило допуска к реализации

Нельзя реализовывать неподтверждённое поведение как будто это стандарт Yamaha.

Для каждого правила Smart Arranger должна существовать запись:
- точная модель и версия прошивки, к которой относится утверждение;
- первоисточник и страница/пункт либо описание аппаратного теста;
- ожидаемая последовательность MIDI/секций;
- regression test;
- уровень уверенности: официально документировано / патентное раскрытие / независимо реконструировано / аппаратно проверено.

Пока момент применения нового аккорда внутри секции и поведение MIDI-нот на границах секций не установлены, эти части Style Engine остаются исследовательскими задачами, а не готовыми требованиями.
