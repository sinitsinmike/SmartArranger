# Yamaha Style Engine — NTR, NTT, RTR и преобразование нот

**Исследовательская заметка №3**  
**Основной источник:** Yamaha PSR-SX920/SX720 Reference Manual, firmware 1.10, раздел *Styles → Creating/Editing Styles → SFF Edit*, печатные страницы 29–32.  
**Область применимости:** документ описывает функции Style Creator и параметры SFF в PSR-SX920/SX720. Он не доказывает, что все модели Yamaha используют идентичную реализацию или одинаковые значения по умолчанию.

## 1. Главный вывод

Yamaha SFF не сводится к транспонированию всего MIDI-фрагмента на число полутонов. Документация описывает последовательность:

1. Задать исходный контекст Source Root / Source Chord.
2. При исполнении определить изменение корня аккорда и его типа.
3. Применить NTR (правило преобразования по изменению корня).
4. Применить NTT (таблицу преобразования по изменению типа аккорда).
5. Ограничить диапазон/октаву через High Key и Note Limit.
6. Обработать поведение уже звучащих нот при смене аккорда через RTR.

Yamaha указывает, что эти параметры вместе определяют преобразование исходных нот в реально звучащие ноты. Следовательно, текущий упрощённый глобальный chord transform в Smart Arranger не является эквивалентом SFF.

Источник: Yamaha PSR-SX920/SX720 Reference Manual, pp. 29–32.

## 2. Source Root / Source Chord

Эти параметры описывают исходную тональность/гармонический контекст записанного Source Pattern. В руководстве приведён пример: если исходный паттерн задан как Fm7, то исполнение Fm7 в chord area воспроизводит записанные ноты без гармонического преобразования.

Значение по умолчанию в Style Creator — CM7 (Source Root C, Source Chord M7). Это настройка Style Creator, а не основание считать, что каждый сторонний `.STY` фактически записан в C major.

Важное ограничение: Yamaha предупреждает, что Source Root/Chord следует задавать до записи. Если изменить их после записи, исходный паттерн может не преобразоваться в соответствующие ноты при смене аккорда.

Для Smart Arranger:
- читать Source Root и Source Chord из данных стиля;
- не подменять их безусловным предположением C major;
- хранить исходные значения отдельно от текущего распознанного аккорда.

## 3. NTR — Note Transposition Rule

NTR определяет преобразование нот при изменении корня аккорда.

### Root Trans
Сохраняет интервальные отношения между нотами. Пример Yamaha: C3–E3–G3 при переходе от C major к F major становится F3–A3–C4. Руководство рекомендует этот режим для каналов с мелодическими линиями.

### Root Fixed
Старается удержать ноты вблизи прежнего регистра. Пример Yamaha: C3–E3–G3 при переходе от C major к F major становится C3–F3–A3. Рекомендуется для аккордовых партий.

### Guitar
Специальный режим для гитарного аккомпанемента: преобразование приближает ноты к аккордовым аппликатурам реальной гитары. Для Guitar предусмотрен отдельный набор NTT Type (см. ниже).

**Инженерное следствие:** Root Trans и Root Fixed нельзя заменить одним алгоритмом «прибавить разницу корней». В Root Fixed важен целевой регистр/близость к предыдущему диапазону; Guitar требует отдельной модели.

Источник: Reference Manual, p. 30.

## 4. NTT — Note Transposition Table

NTT определяет, как ноты меняются при изменении типа аккорда. Набор NTT зависит от выбранного NTR.

### Если NTR = Root Trans или Root Fixed

| NTT Type | Описание Yamaha |
|---|---|
| Bypass | При Root Fixed не выполняет преобразование нот. При Root Trans сохраняет интервальное соотношение нот. |
| Melody | Для большинства мелодических линий; Yamaha приводит Bass, Phrase1 и Phrase2 как типичные примеры. |
| Chord | Для аккордовых партий, прежде всего Chord1 и Chord2, предполагающих гармоническую раскладку. |
| Melodic Minor | При переходе major → minor понижает большую терцию над Source Root на полутон; при minor → major повышает малую терцию. Остальные ноты не меняются. |
| Melodic Minor 5th | То же, плюс преобразование квинты для увеличенных и уменьшённых типов аккорда. |
| Harmonic Minor | При major/minor-переходе изменяет терцию и сексту на полутон; остальные ноты не меняются. |
| Harmonic Minor 5th | То же, плюс обработка квинты для увеличенных и уменьшённых аккордов. |
| Natural Minor | При major/minor-переходе изменяет терцию, сексту и септиму на полутон. |
| Natural Minor 5th | То же, плюс обработка квинты для увеличенных и уменьшённых аккордов. |
| Dorian | При major/minor-переходе изменяет терцию и септиму на полутон. |
| Dorian 5th | То же, плюс обработка квинты для увеличенных и уменьшённых аккордов. |

Важное уточнение: в руководстве эти специальные минорные таблицы описаны для секций, которые реагируют только на major/minor, например Intro и Ending. Результат зависит от нот исходного паттерна, предполагаемого типа минорного лада и музыкального режима.

### Если NTR = Guitar

| NTT Type | Описание Yamaha |
|---|---|
| All Purpose | Подходит и для strumming, и для arpeggio. |
| Stroke | Специализирован для strumming; некоторые ноты могут звучать как приглушённые, имитируя гитарный штрих. |
| Arpeggio | Специализирован для арпеджио; Yamaha описывает результат как четырёхнотные арпеджио. |

Не следует применять Guitar NTT к обычным басовым или клавишным партиям.

Источник: Reference Manual, pp. 30–31.

## 5. NTT Bass — slash chords / on-bass

NTT Bass включает реакцию канала на аккорды с отдельной басовой нотой.

Пример Yamaha: при Dm7/G канал с NTT Bass = On транспонирует соответствующие ноты к G, а не к D (корню аккорда). При NTR = Guitar и NTT Bass = On на slash chord реагирует только нижняя нота, обозначенная как Bass внутри гитарной аппликатуры.

Это отдельный параметр. Нельзя считать, что любой канал автоматически использует басовую ноту slash chord.

Источник: Reference Manual, p. 32.

## 6. Настройки Rhythm-каналов

Yamaha прямо рекомендует для Rhythm-каналов, которые не должны реагировать на смену аккорда:

- NTR = Root Fixed
- NTT = Bypass
- NTT Bass = Off

При этих значениях интерфейс Style Creator меняет Source Root / Source Chord на Play Root / Play Chord.

Для Smart Arranger это надёжная документированная отправная точка для Rhythm-каналов, но фактические параметры конкретного `.STY` нужно читать из файла, а не назначать всем каналам по их номеру без проверки.

Источник: Reference Manual, p. 32.

## 7. High Key и Note Limit

### High Key
Ограничивает верхнюю границу транспонирования по корню аккорда. Если рассчитанная нота выше заданной верхней границы, Yamaha переносит её на октаву вниз. Этот параметр действует только при NTR = Root Trans.

### Note Limit Low / High
Задаёт нижнюю и верхнюю границы диапазона нот для Voice, записанного в Style-канале. Цель — не допускать неестественного регистра инструмента, например слишком высоких басовых нот или слишком низких нот пикколо.

Это не то же самое, что общий MIDI transpose или диапазон клавиатуры. Ограничения применяются к результату преобразования нот Style.

Источник: Reference Manual, p. 32.

## 8. RTR — Retrigger Rule

RTR задаёт поведение нот, которые уже звучат в момент смены аккорда.

| RTR | Описанное Yamaha поведение |
|---|---|
| Stop | Ноты прекращают звучать. |
| Pitch Shift | Высота звучащей ноты плавно изменяется без новой атаки, чтобы соответствовать типу нового аккорда. |
| Pitch Shift to Root | Высота изменяется без новой атаки к корню нового аккорда; октава новой ноты сохраняется. |
| Retrigger | Нота запускается заново с новой атакой и высотой, соответствующей следующему аккорду. |
| Retrigger To Root | Нота запускается заново с новой атакой на корне следующего аккорда; октава сохраняется. |

Это особенно важно для реализации MIDI. RTR — не только выбор новой высоты для будущих Note On. Он описывает судьбу уже звучащей ноты. Следовательно, движку потребуется отслеживать активные ноты и их состояние при смене гармонии.

Документация не раскрывает в этом разделе точную MIDI-последовательность для каждого RTR (например, порядок Note Off, Pitch Bend и повторного Note On), точную длительность pitch transition или правила для всех Voice. Эти детали нельзя выдумывать; их следует исследовать отдельно на реальном инструменте или по дополнительным источникам.

Источник: Reference Manual, p. 32.

## 9. Что это означает для архитектуры Smart Arranger

Предлагаемое разделение данных и обработки:

1. **Style metadata:** секция, канал, Source Root, Source Chord, NTR, NTT Type, NTT Bass, High Key, Note Limit Low/High, RTR.
2. **Chord input:** отдельно хранить распознанный chord root/type и slash-bass note.
3. **Conversion stage:** применять NTR к изменению корня, NTT к изменению типа аккорда, затем High Key/Note Limit.
4. **Active-note manager:** хранить активные ноты по каналу/голосу, чтобы корректно реализовать RTR.
5. **Section scheduler:** не смешивать правила гармонической конвертации с логикой перехода Intro/Main/Fill/Ending.
6. **Rhythm exemption:** учитывать документированную комбинацию Root Fixed + Bypass + NTT Bass Off.

Это архитектурная рекомендация для Smart Arranger, а не утверждение о внутреннем устройстве прошивки Yamaha.

## 10. Что пока нельзя считать установленным

Руководство SX920/SX720 описывает назначение параметров, но не даёт полного алгоритма:
- математические таблицы всех NTT для всех типов аккордов;
- точные правила выбора голоса/инверсии во всех случаях Root Fixed;
- точный алгоритм Guitar voicing;
- точную MIDI-реализацию RTR;
- момент фиксации нового распознанного аккорда относительно доли/такта;
- обработку смены аккорда при удерживаемых нотах в каждом режиме;
- все детали поведения для SFF1, SFF2 и SFF GE.

Поэтому таблица выше — спецификация значений, явно описанных в руководстве, а не готовая полная реализация Yamaha SFF.

## 11. Рекомендуемые следующие исследования

1. Проверить бинарную структуру CASM и соответствие параметров NTR/NTT/RTR полям конкретных `.STY`.
2. Собрать тестовые Style с одинаковым MIDI Source Pattern и разными NTR/NTT/RTR; записать MIDI/audio output на реальном SX920 или совместимой модели.
3. Отдельно исследовать алгоритм распознавания аккорда и разделение chord root / on-bass input.
4. Измерить поведение RTR на удерживаемых нотах, включая фактические Note Off, повторные Note On и pitch changes.
5. Сопоставить SX920/SX720 с SX900 и Genos по соответствующим руководствам, не переносить поведение автоматически.
6. Только после этого составить тестируемую внутреннюю спецификацию Smart Arranger и план реализации.
