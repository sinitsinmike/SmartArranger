# Yamaha Style Engine — исследование и предварительные выводы

Статус: начальный этап исследования. Документ отделяет официально описанное поведение от неизвестных деталей. Это НЕ полная спецификация Yamaha Style Playback Engine.

## 1. Официальные источники Yamaha

### PSR-SX920 / SX720 Reference Manual
Официальный PDF:
https://usa.yamaha.com/files/download/other_assets/5/2328055/PSR-SX920_reference_manual_En_B0.pdf

Раздел **Section Change Timing** (в разных редакциях PDF номер печатной страницы может отличаться; искать по точному заголовку).

Для PSR-SX920/SX720 документированы режимы переключения Main:

- **Immediate**: выбранная Main начинает воспроизводиться со следующей доли; при этом она входит с соответствующей доли, а не обязательно с первой доли своего паттерна.
- **Next Bar**: переключение выполняется на границе следующего такта с оговорённым Yamaha исключением для команды, поступившей в самом начале такта.
- При включённом Auto Fill In Yamaha ограничивает поведение переключения правилами Next Bar. В руководстве также перечислены ограничения для Audio Styles.

Для переключения секций внутри Intro/Ending предусмотрена отдельная настройка:

- **Next Bar** — переход по правилу границы такта;
- **End of Section** — дождаться завершения текущей секции;
- для некоторых переходов Intro/Ending есть специальные исключения, описанные в руководстве. Не переносить эти правила на все модели без проверки.

Это прямое официальное подтверждение для указанного семейства и поколения, а не универсальная спецификация всех Yamaha.

### PSR-SX920 / SX720 Owner's Manual
Официальная страница загрузок:
https://usa.yamaha.com/products/contents/keyboards/downloads/manuals/index.html?c=keyboards&k=SX920&l=en

В пользовательском руководстве описано общее поведение:

- Intro звучит в начале, после завершения сопровождение переходит к Main;
- Main повторяется до выбора другой секции;
- Ending завершает исполнение, после чего автоаккомпанемент автоматически останавливается;
- Auto Fill In вставляет Fill при переключении вариаций Main.

Это описывает пользовательское поведение, но не раскрывает все внутренние алгоритмы планировщика.

### Официальные руководства по SFF

- PSR-S670 Reference Manual: https://uk.yamaha.com/files/download/other_assets/3/875933/psrs670_en_rm_a0.pdf
- PSR-S975/S775 Reference Manual: https://europe.yamaha.com/files/download/other_assets/7/1153387/psrs975_s775_en_rm_a0.pdf
- PSR-730 technical/reference document: https://usa.yamaha.com/files/download/other_assets/6/334546/PSR730E.pdf

В документации Yamaha описаны элементы преобразования нот стиля:

1. Source Root / Source Chord — исходная тональная/гармоническая опора паттерна.
2. NTR (Note Transposition Rule) — правило транспонирования при изменении корня аккорда.
3. NTT (Note Transposition Table) — таблица преобразования при изменении типа аккорда.
4. High Key / Note Limit — ограничения регистра и диапазона.
5. RTR (Retrigger Rule) — обработка удерживаемых/звучащих нот при смене гармонии.

Точные таблицы параметров необходимо извлечь и сопоставить отдельно для SFF1, SFF2 и SFF GE. Нельзя считать, что одинаковые названия во всех поколениях означают абсолютно одинаковую реализацию.

## 2. Что эти документы НЕ доказывают

SFF/CASM-документация объясняет преобразование нот исходных паттернов. Сама по себе она не является полной спецификацией:

- алгоритма распознавания аккордов и режимов аппликатуры;
- момента, когда распознанный аккорд становится активной гармонией сопровождения (сразу, на следующей доле, на следующем такте и т. п.);
- полной очереди запросов Intro/Main/Fill/Break/Ending;
- всех приоритетов при быстрых повторных нажатиях;
- поведения Note Off и MIDI-контроллеров на границах секций;
- внутренних правил синхронизации движка.

Эти пробелы нельзя заполнять предположениями.

## 3. Независимые источники — только вторичные свидетельства

Yamaha Style Studio:
https://github.com/jozphe/Yamaha-Style-Studio

Проект полезен как независимая реализация чтения/записи SFF2 и CASM, в том числе для исследования CSEG/Ctab/Ctb2. Это не нормативная документация Yamaha. Любое наблюдение из исходников нужно помечать как reverse-engineered и сверять с файлами/реальным инструментом.

## 4. Матрица доказательств

| Вопрос | Статус | Что можно утверждать |
|---|---|---|
| Intro заканчивается переходом в Main | Официально описано в руководствах конкретных моделей | Переход после завершения Intro; точные edge cases требуют уточнения по модели |
| Ending заканчивается остановкой ACMP | Официально описано в руководствах конкретных моделей | Автоматическая остановка после окончания Ending |
| Переключение Main | Официально описано для SX920/SX720 | Есть Immediate и Next Bar; имеются исключения |
| Переключение секций внутри Intro/Ending | Официально описано для SX920/SX720 | Есть Next Bar и End of Section с исключениями |
| Auto Fill при смене Main | Официально описано на пользовательском уровне | Fill вставляется между вариациями; полная таблица очередей/приоритетов ещё не извлечена |
| SFF source/root/chord conversion | Официально описано | Source Root/Chord, NTR, NTT, High Key, Note Limit, RTR |
| Точный алгоритм chord recognition | Не установлен | Нужны отдельные источники по конкретной модели |
| Момент фиксации смены аккорда | Не установлен | Не предполагать Immediate/Beat/Bar без подтверждения |
| Полная state machine Fill/Break/Ending | Частично описана | Нужна постраничная сверка руководств конкретной модели |
| Note Off на границах секций | Не установлен | Нужен официальный источник или MIDI capture реального инструмента |

## 5. Следующие задачи исследования

1. Извлечь полные разделы SX920/SX720 о Style playback, Section Change Timing, Intro/Ending, Auto Fill, Break, Chord Fingering и распознавании аккордов.
2. Сравнить SX900/SX700, Genos/Genos2, SX920 и более ранние модели; каждое правило привязать к конкретной модели/поколению.
3. Извлечь полные таблицы NTR/NTT/RTR и сравнить их для SFF1/SFF2/SFF GE.
4. Исследовать патенты Yamaha и технические публикации. Патент подтверждает раскрытый способ/изобретение, но не доказывает, что конкретная коммерческая модель реализует каждый описанный пункт.
5. Исследовать независимые SFF-парсеры и реальные style-файлы только как вторичные источники.
6. Для неописанных деталей подготовить протокол испытаний на конкретной Yamaha с записью MIDI OUT/USB MIDI и временных меток.

## 6. Условие допуска к реализации

Не заменять текущую глобальную C-major-транспозицию другой догадкой. Не заявлять Yamaha-compatible playback до реализации per-part CASM/NTR/NTT/RTR и подтверждения переходов/синхронизации тестами.
