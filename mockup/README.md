# Smart Arranger skin concepts

The comparison board in [skin-variants-vintage-stage-neon.png](skin-variants-vintage-stage-neon.png) contains three visual directions:

- **A — Vintage:** graphite hardware panel with warm gold controls. Selected for the next implementation pass.
- **B — Stage:** clean navy interface with cyan accents.
- **C — Neon:** plum stage-console look with magenta and teal highlights.

[Original-mockup.png](Original-mockup.png) is the original full-featured reference supplied for the project.

These are visual concepts, not screenshots of implemented plugin builds. The on-screen keyboard shown in the concepts is deferred to a later feature pass.
